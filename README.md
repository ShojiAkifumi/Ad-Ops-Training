# 広告指標トレーニング

広告運用の指標（CPC・CTR・CVR・CPA・CPM・ROAS・ROI・LTV など）を、用語クイズと実践的な計算問題で学ぶ静的Webゲームです。ビルド不要で、`index.html` をブラウザで開くだけで遊べます。

## モード
- **単語クイズ**：用語の意味・正式名称（例：CTR → Click-Through Rate）を4択で出題
- **用語クイズ**：運用の考え方・計算式の4択と、計算式の穴埋め。問題文と選択肢に出てくる用語の解説ヒント付き（略語は正式名称も表示）
- **計算チャレンジ**：運用シーンを元にした計算問題（毎回ランダムな数値）。初級・中級・上級を選べます

## 機能
- 制限時間・タイムボーナス・コンボ・ランク判定
- 計算問題のヒント（得点半分）と電卓
- 回答ごとの解説（計算過程）と、結果画面でのふりかえり
- 指標の早見表（ヘッダーからモーダルで表示）
- トップに学習記録（正答数/問題数・正答率・コンプリート率・獲得実績）を表示。実績は12種類
- 記録・自己ベスト・設定をブラウザに保存（localStorage）

## ファイル構成
- `index.html` 画面
- `css/style.css` スタイル（ダークモード対応）
- `js/data.js` 指標の定義と用語クイズ
- `js/problems.js` 計算問題ジェネレーター（問題を増やすときはここに追加）
- `js/terms.js` 用語辞書（ヒント）、単語クイズ、計算式の穴埋め問題
- `js/app.js` ゲーム進行
- `js/stats.js` 学習記録・コンプリート率・実績（バッジ）
